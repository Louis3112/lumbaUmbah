# :bangbang: **POP Final-Semester Project for 4th Semester**  :bangbang:

## :dolphin: :shirt:  **lumbah-umbah** :dolphin: :shirt:
Our final-Semester Project for Platform-Oriented Programming (POP) in 4th Semester.
Platform-Oriented Programming is an approach to software development where the code is synced with the characteristics of target platform.
On this project, the code is synced with the characteristics of website platform (HTML,CSS Framework and JavaScript Framework)

Lumba Umbah is a laundry service website that offers laundry by weight. The name Lumba Umbah is derived from the Javanese phrase "umbah-umbah", which means washing clothes.
Lumba Umbah carries the motto: "Biar kami yang umbah" or “Let us do the washing for you.”

Lumba-Umbah is developed using, HTML, Tailwind CSS, React.js as framework and Javascript on the front-end. For the back-end, we are using GoLang, with Gin and Gorm as framework.
Last but not least, Docker for containerization and PostgreSQL as the database

## :arrow_forward: **Installation and Usage** 
To install this project, please proceed these steps:
1. Clone the repository: **`git clone https://github.com/Louis3112/lumbaUmbah`**
2. Navigate to the project directory: **`cd lumbaUmbah`**
3. Look at the project by clicking index.html
4. Type npm i to install node_modules
5. Run npm run dev to start the development server on localhost
6. Vite will start the development server and there will be a link Local: http://localhost:YOUR_PORT -- click it to open the site
7. Your default browser will open the site automatically
